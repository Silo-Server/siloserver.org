title: Connect and start watching

You need an account on the server you're joining: an invitation link or a
username and password from the person who runs it. Some servers instead let
you sign in with your organization's account, and create your Silo account the
first time you do. An account works only on the server that created it.

## Accept your invitation

The invitation link opens in your web browser, even on a phone or tablet.

1. Open the link. The page says **Welcome to** and the server's name.
2. Choose a password, enter it again under **Confirm password**, and select
   **Create account**. Your username is the email address shown on the page.
3. On **Who's watching?**, you can add a profile for each person in your
   household with **Add profile**, or select **Just me for now**. You can add
   profiles later; see [Profiles, PINs, and shared devices](/docs/profiles).
4. Select **Continue**. If you added profiles, choose yours. The web app opens
   on Home, and you can start watching in the browser straight away.

On an Android phone or tablet, the page also offers **Open in the Silo app**
if you've installed it. If the page says **Invitation unavailable**, the link
was already used or has expired. Sign in if you already created your account,
or ask for a new invitation.

If you were given a username and password instead, skip to signing in.

## Sign in

### In a browser

1. Open the server address. The person who runs the server gives you this;
   it isn't siloserver.org.
2. Enter your username (or email address) and password, and select
   **Sign in**. If the page shows other sign-in options, use the one you were
   told to use.
3. On **Who's watching?**, choose your profile and enter its PIN if asked.

If you sign in with your organization's account, select its button on the
sign-in page and sign in on the page it opens. When that's the only way in,
the server's address takes you there straight away. Some servers use your
organization's username and password in Silo's own form instead.

### On a phone or tablet

1. Open Silo, enter the full server address, including `https://` and any
   port number you were given, and select **Connect**.
2. Enter your username (or email address) and password, and select
   **Sign in**.
3. On **Who's watching?**, choose your profile and enter its PIN if asked.
   Silo opens on Home.

If the server offers **Sign in with** and your organization's name, select it.
Silo opens the sign-in page in your browser and returns to the app when you're
done. To use a Silo password on that server, select **Sign in with a password**.

Your account is the sign-in. A profile keeps one person's progress,
preferences, and limits, so use your own profile to keep your viewing
separate from everyone else's.

## Play something

Open a library, choose a movie or episode, and select **Play**. If you've
already started it, you can pick up where you left off. See
[Watch movies and series](/docs/watch-movies-and-series) for audio, subtitles,
and other playback controls.

If a library looks empty, make sure you're on the right server and profile.
The person who runs the server decides which libraries each account can see.
If the server address won't open in a browser on the same device, the problem
is the address or the network, not your password.
