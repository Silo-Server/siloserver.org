Silo 1.0 plays movies and series in the web app and in the Apple and Android
apps. This table lists the 1.0 features and the apps that have them. It comes
from the [1.0 release plan](https://siloserver.org/milestone/1.0/). Select a
feature to open its guide.

<FeatureSupport />

Server settings are always managed in the web app, from any computer. To use
an app built for Jellyfin, see [Connect a Jellyfin-compatible app](/docs/jellyfin-apps).
Audiobooks, ebooks, Watch Party, and other [Beta features](/docs/beta) list
their apps on their own pages.
