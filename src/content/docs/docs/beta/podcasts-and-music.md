## Podcasts

The web admin's library form includes a **Podcasts** type, and the server
can scan podcast files into that library. No Silo app can browse or play a
podcast library yet, and Silo doesn't subscribe to podcast feeds. Use a
dedicated podcast app for subscriptions, episode downloads, and listening.

## Music

Silo has no music library type, so the library form has no **Music**
option and no Silo app plays music. Use a dedicated music app for albums,
artists, and playlists.

For the media types Silo can play, see
[library types](/docs/manage-libraries#choose-a-library-type),
[audiobooks](/docs/listen-to-audiobooks), and [ebooks](/docs/ebooks).
