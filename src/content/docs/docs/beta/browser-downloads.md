:::caution[Beta]
Browser file downloads are outside the supported 1.0 scope. The control depends on your account's download permission and may vary between builds.
:::

The web app can save an original media file through your browser. You choose the file version and the browser handles the transfer.

| Client | Available actions |
| --- | --- |
| Web | Save an original file from an item's Download action. |
| iPhone, iPad, Android phone and tablet | Use the separate [managed downloads](/docs/downloads) workflow for supported offline video. |

## Save a file

1. Sign in to the web app and open a movie or episode.
2. Open the item's overflow menu and select **Download**.
3. Choose a version from the download dialog.
4. Check the browser's download list and wait for the transfer to finish.

The action appears only when your account allows downloads and the item has files. An ebook detail page can also offer a Download button when those conditions are met.

You receive the selected file, so playback after saving depends on an application that can open that format. This does not create an entry in a Silo mobile app's offline library or provide that app's offline progress workflow.

If a download cannot start, check your sign-in, access to the item, and the server connection, then try again. A successful start only launches the browser transfer; verify that the browser reports completion before relying on the local copy.
