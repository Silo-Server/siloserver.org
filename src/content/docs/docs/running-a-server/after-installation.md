You can use Silo as soon as your first library scans and an item plays. Most admin settings can wait until you need them.

## Step-by-step

If you have not reached playback yet, finish [Install Silo](/docs/get-started/install-silo#5-finish-setup-in-the-browser). Try one movie, episode, or audiobook in the web app, then on the device you expect to use most. Check sound, seeking, and resume.

## What to decide first

Before relying on the server, make a [backup and recovery plan](/docs/running-a-server/backup-restore). Keep the encryption key safe and record the image version, data paths, and any external storage.

Use a separate account for each person you invite. Your admin password gives control over the server, not just permission to watch its media.
