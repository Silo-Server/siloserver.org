Sections are the rows people browse on Home and library pages. Use **Admin > Sections** to set their shared content and starting order.

## Add a row

1. Choose **Home** or **Library**. For a library row, select the target library.
2. Choose **Add Section**.
3. Select a **Section Type** and enter a **Title**. For a collection row, choose an existing collection.
4. Set **Item Limit** and keep **Enabled** on. Review the library or filter controls shown for that section type.
5. Choose **Add Section**, then open the target page in the app.

**Add from Gallery** offers prepared sections. Review their source and library choices before adding them.

## Change the order or hide a row

Drag sections into order. Open a section to change its title or contents and choose **Save**. Turn off **Enabled** to hide it without deleting its configuration.

**Restore Defaults** changes the shared arrangement. Read its confirmation before using it on a server you have already curated.

Viewers can have their own saved order. If your order change appears for a new profile but not an existing one, inspect that profile's settings before recreating the sections.

## A row is missing or empty

Check the selected Home or Library scope, the row's **Enabled** setting, and any collection or filter it uses. Then check the viewer's library access and profile restrictions.

Recommendation rows depend on [recommendation data](/docs/recommendations). Renaming or moving a row does not rebuild those results.
